Destroying the `<ckeditor>` component while the editor is still being created no longer leaks the editor. The pending creation no longer fails with `TypeError: Cannot read properties of null (reading 'insertBefore')`, and the editor is destroyed as soon as its creation completes, so features such as real-time collaboration close their connection once the user leaves the page.

Errors from a creation that settles after the component has been destroyed are no longer emitted through the `error` output or printed to the console.
