Error handling demo

There is no Watchdog any more, so a crashed editor stays as it is instead of being silently rebuilt. Simulate error throws an error that is reported through the (error) output and leaves the editor working — type something first and see that it stays.

An error belongs to the editor it came from. Break one and only that one reports.

The same two editors, now sharing one Context. Sharing it does not make them share their errors either — break one and only that one reports. An error attributed to the context itself rather than to an editor does not reach (error) at all; register your own callback with Editor.onEditorError() if you need those.
